# Zenodo Release Plan

Do not mint a DOI for the release candidate until a repository curator confirms the dated source-license record and at least one external reproduction is complete.

When ready:

1. Create a GitHub release tag.
2. Connect the repository to Zenodo.
3. Upload the release archive and dataset manifest.
4. Verify title, authors, ORCID fields if available, license, and related identifiers.
5. Confirm that the DOI resolves and update `CITATION.cff`.
