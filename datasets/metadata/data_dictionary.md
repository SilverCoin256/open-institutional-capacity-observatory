# OICO Data Dictionary

This dictionary describes the canonical v1 tables generated from frozen public-data snapshots.
Every table is regenerated by `oico reproduce`; do not edit processed tables by hand.

## institutions

| field | type | nullable | description |
|---|---:|---:|---|
| institution_id | string | False | Stable OICO identifier. |
| name | string | False | Human-readable institution name. |
| jurisdiction | string | False | Primary jurisdiction represented by the dataset. |
| sector | string | False | Public, private, higher education, or mixed sector. |
| domain | string | False | Research domain represented by the institution. |
| unit_of_observation | string | False | Primary analytical unit available in v1. |
| source_dataset_id | string | False | Dataset family that introduced the institution. |
## queue_observations

| field | type | nullable | description |
|---|---:|---:|---|
| observation_id | string | False | Stable row identifier. |
| institution_id | string | False | Foreign key to institutions.csv. |
| period | string | False | Reported fiscal year, quarter, month, or date label. |
| period_start | string | True | ISO-style start date where inferable. |
| period_end | string | True | ISO-style end date where inferable. |
| pending | integer | False | Cases/items pending at the reporting boundary. |
| received | integer | True | Cases/items received during the period. |
| completed | integer | True | Cases/items completed during the period. |
| qai | number | True | Queue Acceleration Index recomputed by OICO. |
| source_qai | number | True | QAI value inherited from the source snapshot. |
| qai_delta | number | True | Difference between recomputed and inherited QAI. |
| quality_flags | string | False | Pipe-separated validation notes. |
| source_dataset_id | string | False | Source dataset family. |

## Metric Boundaries

- QAI is a descriptive flow metric, not a causal capacity estimate.
- SEDI is a theory-guided degradation index, not validated ground truth.
- ASI measures textual accountability specificity, not operational enforcement.
