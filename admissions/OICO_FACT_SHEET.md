# OICO Factual Sheet

## Problem

Institutions increasingly process and oversee complex decisions. OICO studies whether observable public traces can show review pressure without treating a proxy as institutional quality.

## Built

- A public Python package and CLI.
- Frozen public-data snapshots with provenance, checksums, schemas, and license notes.
- A stable QAI indicator, a beta ASI document corpus, and three explicitly experimental models.
- A reproducible EOIR flagship case with table, figure, report, and limitations.
- Tests, notebooks, benchmarks, teaching material, a static research site, release artifacts, and a replication protocol.

## Verifiable status as of 2026-08-10

- Public GitHub repository and stable `v1.1.0` tag.
- Local clean-room reproduction passes.
- GitHub Actions workflow configured for Python 3.10, 3.11, and 3.12.
- No DOI, PyPI publication, independent reproduction, named lab use, professor recommendation, course link, published citation, or external conference artifact verified yet.

## Limitation

The flagship result is descriptive. It does not identify staffing, intent, causality, legal compliance, or institutional quality.
