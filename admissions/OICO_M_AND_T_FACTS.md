# OICO Interdisciplinary Facts For M&T Context

This is not an admissions strategy or an M&T admissions claim. It is a factual map of the project's disciplines.

- Engineering/software: Python package, CLI, data validation, deterministic outputs, tests, CI, release artifacts.
- Quantitative analysis: stock-flow metrics, baseline comparisons, correlations, trend summaries, sensitivity checks.
- Public administration: workload, throughput, queues, reporting definitions, institutional capacity boundaries.
- AI governance: accountability-language corpus and experimental governance models, explicitly kept outside the flagship claim.
- Open science: provenance, licenses, checksums, reproducibility, citation metadata, community issue routes.

The project demonstrates integration of these fields; it does not claim that Penn, M&T, or any other institution endorses it.
