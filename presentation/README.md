# External Validation Presentation Pack

These are practice materials for explaining OICO to researchers, teachers, reviewers, and judges. They are not an official ISEF submission and contain no claim of finalist status, adoption, or external validation.

The presentation thesis is deliberately narrow:

> OICO is an auditable open package for measuring observable workload pressure without pretending that a public proxy is institutional capacity itself.

Use the poster, short pitch, and Q&A bank together. Lead with the research question, show the raw-to-result path, state the limitation before a reviewer asks, and invite an independent reproduction.
