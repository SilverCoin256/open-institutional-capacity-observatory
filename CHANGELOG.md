# Changelog

## 1.0.0-rc1

- Created the canonical Open Institutional Capacity Observatory monorepo.
- Added raw-source snapshots for EOIR, USCIS, CFPB, SEC, and ASI materials.
- Added deterministic data builder, schema validation, checksums, manifests, and validation reports.
- Added QAI, SEDI, Authorization Saturation, Procedural Capacity, and ASI metric modules.
- Added benchmark baselines, reproducible SVG figures, notebooks, teaching material, website, release metadata, and community governance files.
- Added validated project-root discovery so non-editable installs can reproduce a checked-out archive from notebooks and automation runners.
- Added a dated, source-by-source redistribution review based on official agency policies.
- Hardened all five metric/model modules against missing, malformed, conflicting, and extreme inputs.
- Corrected the halved-throughput intervention so it increases utilization rather than duplicating the doubled-capacity scenario.
