# Changelog

## 1.1.1 - 2026-09-04

- Final release: reconciles EOIR frozen-snapshot provenance and separates the 11-row artifact window from the FY2016-FY2024 Study 1 inference window.
- Synchronizes the independent replication protocol and adds full Study 1 coverage to CI.
- Disables automatic PyPI publication until a valid Trusted Publisher is configured; no PyPI publication is claimed.
- Declares OICO frozen for external review after this release.

## 1.1.0 - 2026-08-10

- Added the dependency-free OICO Study 1 comparative analysis across four frozen public-data systems.
- Added conventional queue baselines, within-system comparisons, explicit noncomparability rules, machine-readable results, and falsification records.
- Added `oico study1` and `oico reproduce --full`.
- Added the ultimate baseline and external-standards audits, project-differentiation scorecard, ownership audit, and public Why This Exists page.

## 1.0.0 - 2026-08-10

- Promoted the reproducible EOIR queue analysis to the stable flagship case study.
- Classified QAI as a stable descriptive indicator, ASI as beta, and the remaining formal models as experimental.
- Added a clean-room replication protocol, standards audit, design-decision record, AI-use disclosure, scorecard, and external-validation tracker.
- Added public package metadata, GitHub Pages deployment, coverage enforcement, and an external researcher onboarding path.

## 1.0.0-rc1

- Created the canonical Open Institutional Capacity Observatory monorepo.
- Added raw-source snapshots for EOIR, USCIS, CFPB, SEC, and ASI materials.
- Added deterministic data builder, schema validation, checksums, manifests, and validation reports.
- Added QAI, SEDI, Authorization Saturation, Procedural Capacity, and ASI metric modules.
- Added benchmark baselines, reproducible SVG figures, notebooks, teaching material, website, release metadata, and community governance files.
- Added validated project-root discovery so non-editable installs can reproduce a checked-out archive from notebooks and automation runners.
- Added a dated, source-by-source redistribution review based on official agency policies.
- Hardened all five metric/model modules against missing, malformed, conflicting, and extreme inputs.
- Corrected the halved-throughput intervention so it increases utilization rather than duplicating the doubled-capacity scenario.
