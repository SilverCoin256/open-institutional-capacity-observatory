Reproduce the flagship result

The final v1.1.1 protocol rebuilds the tracked EOIR outputs, verifies the frozen inputs, and writes a machine-readable report. Use oico reproduce --full to run the comparative Study 1 layer. It is designed for a clean checkout rather than a trusted local state.

Three commands after environment setup

python -m pip install -e .
oico reproduce --full
python -m unittest discover -s tests

Expected runtime is short on a current laptop. The full reproduction writes the flagship report, Study 1 outputs, canonical EOIR table, and figures.
