# OICO v1.0.0 Release Report

Version: `1.0.0`

Status: technically stable for the documented descriptive workflow. Independent validation, DOI deposit, PyPI publication, and external adoption remain separate open evidence states.

## Stable release evidence

- EOIR flagship pipeline is reproducible from tracked snapshots.
- QAI has formula fixtures, boundary tests, missing-data behavior, and explicit non-claims.
- Data manifests, checksums, source register, transformation log, and license review are included.
- All five notebooks execute in the clean-room workflow.
- Package distributions build and metadata checks run in CI.
- GitHub Actions tests Python 3.10, 3.11, and 3.12.
- The release archive is deterministic and has a SHA-256 sidecar.
- The final archive includes the standalone `examples/flagship/run_flagship.py` entrypoint.
- No credentials are stored in the repository.

## Scientific scope

QAI is the stable descriptive indicator. ASI is beta. SEDI, Authorization Saturation, and Procedural Capacity are experimental. This hierarchy prevents formal scenarios from being mistaken for calibrated empirical measures.

## External evidence

The project is at external evidence Level 0 as of 2026-08-10. No independent reproduction, named external user, course link, scholarly citation, conference artifact, DOI, or package-index publication is claimed.

## Release limitations

- The public data are frozen snapshots rather than live feeds.
- Source definitions and coverage may change over time.
- The flagship result is descriptive and non-causal.
- A DOI requires an authenticated archive deposit and verification.
- JOSS readiness is time-gated by public development history and external use.
