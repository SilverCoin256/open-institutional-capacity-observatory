# Academic Adoption Strategy

The goal is named use, not vanity metrics.

## Research Labs

Problem solved: reduces the time needed to assemble public institutional-capacity examples.

Switching-cost reducer: frozen data, schemas, examples, and explicit limitations.

Hard to ignore: a lab can add one new institution without rebuilding the measurement framework.

## Faculty

Problem solved: provides a reproducible teaching case where metrics are useful but contestable.

Switching-cost reducer: professor guide, assignment prompt, and no dependency stack.

Hard to ignore: students can reproduce results and critique validity in one class session.

## Graduate Students

Problem solved: gives a template for building defensible measurement infrastructure from messy public traces.

Switching-cost reducer: data dictionary, manifest, and benchmark outputs.

Hard to ignore: extension pathways can become publishable replication notes or course projects.

## Policy Researchers

Problem solved: turns institutional bottlenecks into transparent variables and caveated indicators.

Switching-cost reducer: public-data-only release candidate and readable source register.

Hard to ignore: avoids black-box scoring and foregrounds misuse risks.

## AI Governance Researchers

Problem solved: connects document accountability, oversight capacity, and procedural safeguards.

Switching-cost reducer: ASI codebook-style outputs and benchmark tasks.

Hard to ignore: creates a bridge between governance text and administrative capacity.

## Conference Demo

Demo story: reproduce the observatory, inspect one provenance chain, run a benchmark, and add a source-register row for a new institution.

Success criterion: at least one external attendee opens a reproducibility issue, forks for a course, or requests a lab integration.
