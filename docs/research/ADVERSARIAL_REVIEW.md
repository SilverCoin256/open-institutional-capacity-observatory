# Adversarial Review

## Strongest rejection

"This is a carefully packaged descriptive backlog ratio around a familiar idea. The sample is one institution, the flagship source provenance is inherited, the named index is not mathematically novel, and the benchmark labels are not independent ground truth. Why should a lab adopt it rather than compute a backlog ratio in an afternoon?"

That rejection is substantially fair.

## Responses and remaining remedies

| Risk | Current response | Remaining remedy |
|---|---|---|
| Novelty inflation | Publicly demote QAI to a descriptive normalization | Publish a comparison study across independent agencies. |
| Single-case inference | Limit flagship claim to EOIR FY2016-FY2024 | Add a preregistered multi-institution panel. |
| Provenance gap | Preserve checksum and caveat; exclude later rows from inference | Re-fetch and independently archive each source release. |
| Proxy benchmark labels | Label tasks as pilots; prohibit public leaderboard | Obtain expert labels with adjudication and held-out validation. |
| AI governance overreach | Separate text coding and scenarios from flagship claim | Validate against observed governance actions and outcomes. |
| Scope creep | Freeze experimental modules and keep one canonical case | Accept only work that improves the core measurement contract. |
| Maintenance risk | No runtime dependencies, CI matrix, checksums, issue templates | Name maintainers and create a funded maintenance plan. |
| Adoption risk | Quickstart, notebooks, teaching guides, issue route | Obtain an independent reproduction and documented user feedback. |
| Ethical risk | Misuse statements and no individual ranking | Add domain-specific review before new sensitive datasets. |
| Citation risk | CFF, release metadata, archival packet without invented DOI | Deposit a real DOI only after independent validation and release review. |

## Kill conditions

The project should remain frozen or be retired if independent reviewers find that the source rows are fabricated, irreconcilable, materially miscomputed, or legally non-redistributable. It should not be expanded to compensate for a weak empirical contribution with more modules or branding.
