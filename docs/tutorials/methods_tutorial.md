# Methods Tutorial

This tutorial frames OICO as a methodological case study, not a finished theory of institutions.

## Step 1: Define The Observable

Public data rarely exposes true capacity. OICO starts from observables:

- pending workload
- completions
- complaint or filing volume
- public review output
- governance document text

## Step 2: Choose A Measurement Model

Use QAI when the system reports a queue over adjacent periods.

Use SEDI when multiple public indicators plausibly describe degradation or erosion.

Use ASI when the research question concerns textual specificity of accountability.

Use authorization/procedural models for simulation, teaching, and benchmark baselines unless calibrated.

## Step 3: Separate Evidence From Interpretation

OICO tables contain measurements. Interpretation belongs in papers, notebooks, and discussion sections where assumptions can be argued explicitly.

## Step 4: Build The Extension

For a new institution:

1. Freeze raw data.
2. Compute checksums.
3. Write source metadata.
4. Map variables to the canonical model.
5. Add validation.
6. Document limitations.
7. Add a baseline only if a benchmark target is defensible.

## Step 5: Review Like A Skeptic

Ask:

- Could a reporting-definition change explain the result?
- Is the denominator stable?
- Are labels independent or derived from the metric itself?
- Would an affected institution consider the claim fair?
- Can a second lab reproduce the result without private access?
