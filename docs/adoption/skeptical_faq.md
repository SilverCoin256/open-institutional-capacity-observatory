# FAQ For Skeptical Researchers

## Why is this not just a collection of CSV files?

Because the release includes schemas, provenance, transformations, checksums, validation, metric documentation, figures, benchmarks, teaching material, and release packaging.

## Why should I trust the metrics?

You should not trust them blindly. OICO documents definitions, assumptions, limitations, and expected misuse so that researchers can evaluate the measures rather than inherit opaque scores.

## Are the benchmark labels real?

Some are proxy or synthetic in v1. The benchmark documentation says so explicitly. This is a release-candidate weakness, not something hidden.

## Why not scrape live data?

Frozen snapshots make the first release reproducible. Optional live-fetch modules can be added after source terms and caching behavior are hardened.

## What would make this publishable?

Independent reproduction, source-license review, one stronger externally labeled benchmark, and a data descriptor or methods paper.
