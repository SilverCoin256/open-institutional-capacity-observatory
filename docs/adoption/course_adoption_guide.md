# Course Adoption Guide

## 50-Minute Class

Use the one-hour tutorial and skip the exit-ticket discussion.

## 90-Minute Seminar

Add small-group critique of one benchmark and one metric.

## Week-Long Module

Day 1: reproduce the release.

Day 2: trace provenance and checksums.

Day 3: critique metrics.

Day 4: design an extension.

Day 5: present extension memos.

## Assessment

Grade students on measurement reasoning, provenance awareness, and limitation handling more than on code complexity.
