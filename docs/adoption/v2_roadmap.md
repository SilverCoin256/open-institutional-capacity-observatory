# Version 2 Roadmap

## Scientific Priorities

- Add independently validated labels for at least one benchmark task.
- Add two new institutional domains with clear public provenance.
- Separate reporting-definition changes from real workload changes where possible.
- Improve ASI reliability with additional human coding.

## Engineering Priorities

- Optional live-fetch modules with cached snapshots.
- R package interface.
- Static documentation site build.
- More robust schema validation.
- Machine-readable ontology export.

## Adoption Priorities

- External reproduction report from one lab.
- Course adoption by one methods instructor.
- Conference demo with a public artifact.
- DOI-bearing release after source-license review.
