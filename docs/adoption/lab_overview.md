# Lab Overview

OICO gives a lab a starting point for studying institutional capacity with transparent public data.

## Why A Lab Would Use It

- It provides schemas and reproducibility conventions before a team starts collecting new sources.
- It defines metrics with assumptions and misuse warnings.
- It includes baseline benchmark tasks and frozen splits.
- It makes provenance and validation visible.

## First Lab Extension

The safest first extension is one new institution with a public queue series. Add it to the source register, map it into `queue_observations.csv`, and test QAI computation.

## Collaboration Model

External labs should begin with a reproduction report, then open a data-source proposal. Maintainers should require source terms, transformation notes, and validation checks before accepting new data.
