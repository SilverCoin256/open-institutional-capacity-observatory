# FAQ

## Is OICO claiming to measure true institutional capacity?

No. OICO measures public traces of capacity: queues, throughput, review intensity, outcome proxies, and governance text. These are observables, not direct access to internal capacity.

## Is v1 a benchmark?

It is benchmark-shaped infrastructure with frozen splits and baselines. It is not yet a mature public leaderboard because several labels are proxy labels or synthetic targets.

## Can I cite it?

Yes, cite the software and dataset metadata using `CITATION.cff`. A DOI should be added only after one is minted through Zenodo, OSF, Dataverse, or a journal archive.

## Can I use it in class?

Yes. The teaching guides are designed for a graduate methods session on public-data measurement, reproducibility, and proxy validity.

## Does it require private credentials?

No. The v1 stable technical release reproduces from frozen public-data snapshots and requires no private token.

## What would make it stronger?

Independent labels, external reproduction, source-license review, more domains, and careful validation against institution-specific ground truth.
