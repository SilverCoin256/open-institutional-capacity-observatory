# Lab Onboarding

This guide is for a research assistant or graduate student joining an OICO-style project.

## First Hour

1. Run the reproduction command.
2. Open the data validation report.
3. Read the metric reference.
4. Inspect one processed table and trace it back to the raw snapshot.

## First Day

- Reproduce the figures.
- Re-run the benchmark baselines.
- Pick one row with a quality flag and explain why it exists.
- Propose a new validation check.

## First Week

- Add a candidate source register entry for a new institution.
- Draft a data provenance memo.
- Review benchmark labels for ground-truth weakness.
- Open an issue describing a scoped extension.

## Lab Norms

- Do not hide warnings to make the release look cleaner.
- Do not describe proxy labels as real labels.
- Do not make adoption claims without named external evidence.
- Prefer small, documented extensions over broad undocumented scraping.
