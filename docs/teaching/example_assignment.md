# Example Assignment

## Prompt

You are evaluating whether OICO is suitable for a computational social science lab studying administrative congestion.

Complete the following:

1. Reproduce the stable technical release.
2. Choose one dataset and trace it from raw snapshot to processed table.
3. Choose one metric and explain its definition, assumptions, limitations, and expected misuse.
4. Evaluate one benchmark task and state whether its labels are ground truth, proxy labels, or synthetic targets.
5. Propose one new public institutional source and map it into the OICO schema.

## Deliverable

Submit a two-page memo plus one appendix table.

## Required Evidence

- Command used for reproduction.
- Validation report status.
- One checksum from the manifest.
- One concrete improvement to provenance or validation.
