# Invitation to Independent Replication

We are seeking independent attempts to reproduce OICO's v1 flagship analysis and identify methodological, documentation, packaging, or data-provenance failures.

The task is intentionally modest: use a clean environment, run the documented command, compare the reference manifest, and report both successes and deviations. A reproduction report does not need to endorse the metric. A careful objection is valuable evidence.

Please use the repository's Independent Reproduction Report issue template. The project will record external evidence only when the attempt is supplied by a real independent researcher and can be distinguished from internal CI.
