# Code of Conduct

OICO is a research infrastructure project. Contributors are expected to be accurate, generous, and careful.

## Expected Behavior

- Critique methods without attacking people.
- Treat uncertainty as something to document, not hide.
- Respect source data terms and affected communities.
- Avoid overstated claims about institutions, agencies, or people.

## Unacceptable Behavior

- Harassment or discriminatory conduct.
- Publishing private credentials or restricted data.
- Misrepresenting proxy labels as ground truth.
- Using OICO outputs to make unsupported accusations.

Maintainers may remove contributions that violate these norms.
