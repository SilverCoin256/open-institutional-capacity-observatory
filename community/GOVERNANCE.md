# Governance

## Maintainer Role

Maintainers protect the scientific credibility of the observatory. Their first responsibility is not growth; it is reproducibility and honest communication.

## Decision Rules

- Data-model changes require documentation and a migration note.
- New benchmark tasks require a baseline, evaluation metric, and limitation statement.
- New source datasets require provenance and license review.
- Adoption claims require named public evidence.

## Release Review

Before a DOI-bearing release:

1. Reproduce the full pipeline in a clean environment.
2. Run the credential scan.
3. Verify all checksums.
4. Review source licenses.
5. Freeze release notes.
6. Archive the release on Zenodo, OSF, or Dataverse.
